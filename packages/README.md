# `packages/`

Каталог агрегирует готовые артефакты для распространения приложения:

- `releases/` — архивы и служебные файлы, которые выдаём команде/CI как слепок диапазона коммитов.
- `deploy/` — пакеты для выкладки (zip/tar или контейнерные файлы), которые формирует агент Deploy Bundle.

При сборке новой версии помещайте файлы строго в соответствующую подпапку и обновляйте этот README при введении новых типов пакетов.
