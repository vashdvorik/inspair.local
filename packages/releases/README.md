# Пакеты релизов

В этой директории агент Release собирает готовые наборы файлов по диапазону коммитов:

- Имя подпапки: `packages/releases/<start>-<end>` (например, `packages/releases/abc123-def456`).
- Содержимое папки копируется из актуальной рабочей копии, а не из git-объектов.
- Внутри каждого пакета должен лежать `README.md` с описанием диапазона, датой сборки и списком включённых путей.

Чтобы сформировать новый пакет вручную:

1. Выберите начальный и конечный коммиты (`git log --oneline`).
2. Выполните дифф (`git diff <start> <end> --name-only`) и соберите перечисленные файлы/папки в `packages/releases/<start>-<end>/` (без `vendor/`, `node_modules/`, `.env`, временных файлов).
3. Добавьте README с кратким описанием и перечислите ключевые изменения.

Деплой-пакет можно собирать на основе этого релиза с помощью агента `60-deploy-bundle-build`.
