# `rules/`: стандарты разработки под Laravel

Папка агрегирует обязательные правила и чеклисты для Laravel-проектов. Эти документы должны учитываться **всеми агентами**, которые формируют требования, пишут код, готовят батчи, релизы и пакеты деплоя.

## Как использовать
- Перед генерацией требований/архитектуры/кода ознакомьтесь с файлами из `rules/`.
- При конфликте правил отдавайте приоритет безопасности, поддерживаемости и официальным рекомендациям Laravel.
- Если нужно уточнить или дополнить правила, вносите правки в файлы `rules/**` и ссылку на изменения фиксируйте в соответствующем батче/документации.

## Состав
- `laravel-development.md` — общие правила разработки: слои/архитектура, контроллеры и FormRequest, авторизация, Eloquent/Query Builder, валидация, очереди/события, кэширование, локализация.
- `laravel-performance.md` — рекомендации по производительности, N+1, индексы, кэш, очереди, сборка фронта.
- `laravel-ops-and-release.md` — требования к окружению, `.env`, миграциям, логированию/наблюдаемости, деплою и релизам.
