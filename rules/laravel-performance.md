# Производительность и эксплуатация (Laravel)

Рекомендации для высоконагруженных проектов и сопровождения.

## Кэш и хранение
- Используйте Redis/кэш там, где есть частые чтения; разделяйте кэш по ключам/тегам, инвалидируйте при изменениях данных.
- Избегайте кэширования персональных данных без сегментации; учитывайте права при хранении в кэше.
- Храните большие блобы вне БД (S3/объектное хранилище), используйте подписи/приватные ссылки.

## База данных
- Индексируйте поля, участвующие в фильтрах/сортировках/джойнах; добавляйте составные индексы там, где нужно.
- Используйте пагинацию/seek для больших выборок; избегайте `SELECT *`, выбирайте только нужные поля.
- Боритесь с N+1: используйте eager loading (`with`, `loadMissing`), `withCount`, batch-загрузку, агрегации.
- Сегментируйте горячие/холодные данные, архивируйте устаревшие записи при необходимости.

## Очереди и фоновые задачи
- Выносите тяжёлые операции в очереди/события/шедулер; настройте retry/timeout/backoff и мониторинг очередей.
- Логируйте длительные операции и ошибки интеграций; используйте метрики для времени выполнения job’ов.

## HTTP/API
- Добавляйте rate limiting для публичных эндпоинтов; кэшируйте ответы там, где это возможно (HTTP кэш, response cache).
- Используйте ETags/Last-Modified, сжатие и CDN для статики.
- Избегайте лишних сериализаций, используйте ресурсы/DTO для API.

## Фронтенд и сборка
- Собирайте фронт (Vite/Webpack) в production-режиме, включайте минификацию и code splitting.
- Следите за размером бандлов, подключайте CDN для тяжёлых зависимостей, используйте HTTP/2 push или prefetch/preload при необходимости.

## Кэш приложений
- В продакшене используйте `php artisan config:cache`, `route:cache`, `view:cache` (если роуты и конфиги не зависят от env во время работы).
- Инвалидируйте кэш конфигов/роутов после деплоя; убедитесь, что `.env` соответствует кешируемым значениям.

## Мониторинг и логирование
- Включайте централизованное логирование; настраивайте уровни логов и маскирование PII/секретов.
- Добавляйте метрики (Prometheus/StatsD) для ключевых операций и очередей; алертите по задержкам, ошибкам, росту времени ответа.

## Тестирование производительности
- Проводите нагрузочные тесты для критичных эндпоинтов/потоков; фиксируйте SLA и критерии деградации.
- Используйте профилирование (Laravel Telescope/Debugbar в dev, Blackfire/XHProf) в безопасной среде.
