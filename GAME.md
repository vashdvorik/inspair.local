# Игра «Нити»: как устроена и как включить

Кабинет участника превращён в игру знакомств: квесты «угадай, кто это», растущая сеть, пять уровней. Бот только напоминает.

## Включение на сервере (один раз)

```bash
php artisan migrate --force
# в .env: OPENROUTER_API_KEY=...   (и APP_URL=https://inspire.education.md)
php artisan config:clear
php artisan ai:recompute-embeddings --force   # векторы теперь считает OpenRouter, старые (Gemini) несравнимы
```

Cron уже запускает `schedule:run` каждую минуту. Расписание: `game:generate-quests` каждые 30 минут, `game:remind` раз в сутки (15:00 UTC).
Собранный фронтенд лежит в `public/build` и едет через git, Node на сервере не нужен. После правок в `resources/js/game` пересоберите у себя: `npm run build`.

## Режимы игры

Админка → «Игра «Нити»» → выбор режима. Хранится в файле `storage/app/game-mode.json` (без запроса в базу на каждую страницу; файл не в git).

- **Выключена** (по умолчанию после деплоя): игры нет нигде. Нет пункта в меню, адреса `/app/account/game…` дают 404, в профиле нет фактов и переключателей игры, «Люди», «Поиск», «Матчи» открыты всем, очки не начисляются, бот молчит, квесты не создаются.
- **Ожидание**: «Люди», «Поиск», «Матчи» закрыты, участники видят экран ожидания и заполняют профиль. Бот молчит.
- **Запущена**: квесты, сеть, уровни, доступ по уровням, напоминания бота.

При выключении данные (очки, факты, нити, квесты) остаются в базе и вернутся при повторном включении. Кнопка «Стереть данные игры» (только в режимах «Выключена» и «Ожидание», с подтверждением) удаляет их безвозвратно. «Закрыть мои контакты» работает всегда, это приватность, а не игра.
Модераторы и организаторы (переключатель «Модератор» в карточке участника) видят всё без уровней.

## Модели ИИ

Админка → «ИИ»: для каждой задачи своя модель и запасная, лимит вызовов в день, кнопка «Проверить», журнал расхода. Один ключ `OPENROUTER_API_KEY`.

## Правила (config/game.php)

- Уровни и пороги: Новичок 0, Активист 100, Союзник 300, Посредник 700, Амбассадор 1500.
- Доступ: «Люди» с уровня 2, «Поиск» и «Матчи» с 3, размещение возможностей с 4.
- Видимость чужого профиля: аватар и имя всегда, регион с 2, «о себе» и факты с 3, ожидания с 4.
- Очки: аватар 30, о себе 50, ожидания 30, регион 10, факт 15 (до 10), верный ответ 20, промах 3, взаимная нить 25.
- После промаха пауза 8 секунд. Штрафов нет, но журнал очков (`xp_events`) и `last_active_at` уже ведутся.
- Квест создаётся из фактов участника, проходит автопроверку ИИ (подходит только одному из троих, нет личных данных); две жалобы скрывают вопрос.
- «Закрыть мои контакты», «Не использовать меня в квестах» и «Тише» настраиваются в профиле.
